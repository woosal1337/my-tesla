# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

- Be kind and respectful to every person.
- Accept that people have different opinions and levels of experience.
- Give and accept constructive feedback.
- Focus on what is best for the project and its users.

These actions are not acceptable:

- harassment, insults, or personal attacks,
- sexual language or images,
- publishing other people's private information, including car locations, without their permission,
- other conduct that is not appropriate in a professional setting.

## Enforcement

Report unacceptable behavior to the maintainers through a private security report on GitHub. Read [SECURITY.md](SECURITY.md) for the steps. The maintainers review each report and keep the reporter's identity private.

The maintainers can remove comments, commits, and issues that break this code, and can block a contributor for a time or for always.
